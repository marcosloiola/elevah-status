Ritmo de consumo do orçamento de custo (burn rate)

Receita acumulada x custo médio acumulado (mês)

Linha azul cheia = receita realizada acumulada. Linha vermelha pontilhada = custo médio acumulado

Receita acumulada x esperada no mês

Linha azul cheia = receita realizada acumulada. Linha azul pontilhada = receita prevista acumulada. Linha vermelha pontilhada = receita necessária acumulada.

Receita acumulada x custo orçado acumulado (ano fiscal)

Linha azul cheia = receita realizada acumulada. Linha vermelha pontilhada = orçamento de custo acumulado, mês a mês, ao longo do exercício.

Receita acumulada x esperada no ano fiscal

Linha azul cheia = receita realizada acumulada. Linha azul pontilhada = receita prevista acumulada. Linha vermelha pontilhada = receita necessária acumulada.

Receita por dia x média esperada por dia

Barras = receita realizada de cada dia (verde = bateu a média necessária do dia, laranja = ficou entre o previsto e o necessário, vermelho = ficou abaixo do previsto). Linha azul pontilhada = receita prevista do mês ÷ dias do mês. Linha vermelha pontilhada = receita necessária do mês ÷ dias do mês.

Orçamento de custo por categoria - consumo do mês

Barra colorida = valor real gasto. Faixa hachurada = parcelas projetadas somadas em cima do real. Categorias sem orçamento definido no budget.csv aparecem sempre "estouradas" quando há gasto.
